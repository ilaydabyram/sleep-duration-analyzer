# Sleep Duration Analyzer

A small beginner-friendly Python project that collects seven days of sleep data and calculates basic statistics.

## Features

- Collects sleep duration for seven days
- Calculates average sleep duration
- Finds the longest and shortest sleep durations
- Displays a simple summary and daily report

## Requirements

- Python 3

No external libraries are required.

## How to run

1. Open this folder in Visual Studio Code.
2. Open the terminal.
3. Run:

   ```bash
   python3 main.py
   ```

4. Enter your sleep duration in hours when prompted.

## Concepts practiced

- Variables and lists
- `input()` and type conversion with `float()`
- `for` loops
- `sum()`, `len()`, `max()`, and `min()`
- Conditional statements
- `enumerate()`
- Formatted strings

## Note

This is a basic programming exercise, not a medical tool. Sleep needs vary from person to person.
